BYTEWYRM

Tiny online tools for small games

Put game data online.
Skip the backend headache.

ByteWyrm gives small Python projects a simple way to save and retrieve data online — without students having to manage HTTP requests, JSON, authentication headers, databases, or servers.

Why ByteWyrm?

Keep the lesson about the game.

Putting data online normally introduces a pile of backend concepts at once. ByteWyrm keeps those details behind a small Python interface so students can focus on the project they are actually building.

Without ByteWyrm
  • HTTP requests and URLs
  • Headers and bearer tokens
  • JSON encoding and parsing
  • Status codes and pagination
  • Database and server details
With ByteWyrm
wyrm.store.add(
    player="Drake",
    score=12500,
)

Store docs

The bits students actually need.

Store is ByteWyrm's first tool: save small structured records, read them back, and optionally ask the server to sort or filter the result.

Store.add()

Save a record using ordinary keyword arguments.

wyrm.store.add(
    player="Drake",
    score=12500,
)
Store.records()

Get records back. Newest records are returned first by default.

records = wyrm.store.records(
    limit=10,
)
Store.latest()

Get only the newest record, or None if the Store is empty.

latest = wyrm.store.latest()

if latest:
    print(latest["score"])
Store.schema()

Inspect the fields and rules configured for the Project's Store.

print(wyrm.store.schema())
Recordssort + filter

Keep queries deliberately small: one filter at a time, plus optional sorting and a limit.

results = wyrm.store.records(
    where="completed",
    equals=True,
    sort_by="score",
    reverse=True,
    limit=10,
)

Data safety

Keep it game data.

ByteWyrm is designed for small amounts of non-sensitive game data only: scores, player nicknames, lap times, progress values, flags and similar project data.

Do not store real names, email addresses, passwords, addresses, private messages, medical information, or other personal, sensitive, or confidential information.
